# 年化 80% 研究（2026-11-04）：把能想到的方法全部測一次

Neo 的要求：「測試所有可能，用什麼方法都可以，找出年化 80% 以上的方法」。這是純研究：沒有改實盤設定，沒有下單。
完整中文報告（含圖）：project files `x80/年化80研究報告.pdf`。

## 結論

在誠實條件下（參數只用前段選、扣交易和借錢成本、不准事後挑、分段看、加密貨幣包括已下架的幣），
**沒有任何方法在 2018 年之後做到年化 80%**；2022-26 整段約 566 個版本裡 0 個到 80%。

* 曾經到 80% 的只有：2014-17 / 2020-21 加密貨幣牛市、2018 年以前做空 VIX（2018-02-05/06 兩天虧 88%）、事後挑的參數或權重。
* 年化 80% 需要長期 Sharpe ≥ 1.07 並用滿 Kelly 槓桿（半 Kelly 要 1.23）。除資金費率套利外，所有方法 2022-26 的 Sharpe 在 −1.0 到 0.9，大部分 0.4-0.7。
* 唯一碰到 80% 的是「做多 BTC / 做空 50 隻山寨幣」2 倍在 2024-26（83%），但 2020-21 每年 −48%（2 倍 −83%），整段 2020-26 1 倍只有 4.8%。

|---|---|---|---|

## 第二輪（2026-11-04）：繼續深挖組合

Neo 的要求：「繼續往所有候選的組合深挖，優化到不能優化為止……直到找到年化 80-90 的方法」。仍然是純研究。
完整中文報告：project files `x80/round2/年化80-90第二輪報告.pdf`。第二輪約 905 個版本（大部分是組合的槓桿設定），兩輪合共約 1,470 個。

**結論：2022-26 仍然沒有一個誠實的版本做到年化 80%；最接近的是 68-74%，回撤 −53% 至 −65%。**

* 最接近的誠實結果：16 個方法的組合，配置法、回看期、波動估計窗口全部只用 2010-17 選出
  （等風險貢獻 104 週、用全部歷史估計波動），加槓桿到 80% 波動（平均約 8 倍）：2022-26 年化 68%（−53%），2018-26 88%（−82%，2020-03）。
  630 個組合版本裡 2022-26 最高 84%（−54%），但那是看完 2022-26 才挑的。
* 很脆弱：2010-17 前三個配置法 Sharpe 1.395 / 1.394 / 1.381 幾乎打和，選中反波動的話 2022-26（80% 波動）只有 37%；
  槓桿上限 5 倍 49%；永續多空書也付借錢成本 53%；去掉本輪新加的 6 個策略 37%。
* 單一新方法：幣圈「做多低資金費率 / 做空高資金費率」樣本外 Sharpe 0.53（19%/年，−49%）；賣 BTC 期權波動率（Deribit DVOL）2023-26 Sharpe 約 0-0.4。
  其餘（13 個幣圈因子、第一輪候選的改良、小時級別規則、做空新上市永續、回撤剎車、Kelly）全部沒有改善或樣本外失效。
* 數學：扣借錢成本後，80% 要組合 Sharpe 約 1.14 並用到約 13-14 倍槓桿；這個組合 2022-26 的 Sharpe 1.21 理論上剛好夠，
  但固定 14 倍實際只有 63%（−86%）：厚尾和每週重設槓桿的成本。

| 組合規則（等風險貢獻 104 週，全部歷史估計波動，2010-17 選出） | 2010-17 | 2018-26 | 2022-26 |
|---|---|---|---|
| 波動 30%（約 3 倍槓桿） | 33%（−26%） | 42%（−42%） | 33%（−22%） |
| 波動 60% | 65%（−49%） | 74%（−70%） | 57%（−42%） |
| 波動 80%（約 8 倍） | 85%（−62%） | 88%（−82%） | 68%（−53%） |
| 波動 100% | 98%（−72%） | 95%（−89%） | 74%（−65%） |
| 對照：反波動 104 週，波動 80% | — | 83%（−86%） | 37%（−66%） |

做法上的修正：資金費率按結算時間歸到前一天（第一輪的資金費率表已重跑，差別 ≤ 0.3 個百分點）；
等風險貢獻改用座標下降法（原來的迭代在有對沖性質的策略時會把權重全部集中到一個策略）；
組合每週換權重和調槓桿按成交名目每邊收 0.10%。
